# Contains Duplicate

**Platform:** LeetCode
**Difficulty:** Easy
**Problem:** [Original Problem](https://leetcode.com/problems/contains-duplicate/description/)

## Problem Summary

You get as input an array of numbers, returning `true` if one or more elements appears twice or more

## Approach

1. Iterate over array of numbers
2. Create a set storing current element
3. validate if the current element exists in set, if it does will return true
4. returning false by default
